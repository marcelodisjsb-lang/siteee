
# Site MT Chata

Um site interativo e personalizado, desenvolvido para apresentar duas telas com mensagens.

## Funcionalidades

- Tela inicial com a mensagem "Oii clique aq".
- Botão interativo para avançar.
- Segunda tela com a mensagem "vc e mt chata".
- Animação de transição entre as telas.
- Design minimalista em preto e branco.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Como acessar

O site pode ser acessado diretamente pelo navegador após sua publicação no GitHub Pages.
